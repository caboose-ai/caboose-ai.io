Moto Edit.

A self-hosted web application for turning raw motorcycle dashcam footage into finished, shareable ride videos — and publishing them to YouTube.

What the application does

Motorcycle helmet and dashcam recordings arrive as many large files — often several gigabytes each, at 4K — containing long stretches of uneventful riding. Moto Edit is the tool its operator uses to turn that raw footage into something watchable, entirely on hardware they own.

Upload and organize Resumable, chunked uploads of multi-gigabyte video files, including whole SD-card folders. Clips are grouped by the date they were recorded.
Trim and cut A timeline editor for splitting a ride into segments and removing the parts that do not belong in the final video.
Condensed ride edits Long rides are compressed into short videos: interesting moments play at normal speed while the rest is sped up as timelapse, and stops are cut out entirely.
Automatic highlight detection The application analyzes motion, camera movement, and engine audio to find the moments worth keeping, and can be steered with a written description of what the rider is looking for.
Privacy blurring License plates and bystanders in the footage are detected and blurred before a video is shared publicly.
Music and finishing An optional music track is mixed underneath the ride audio, with color and fade adjustments applied to the finished edit.
Publish to YouTube A finished video can be uploaded directly to the operator's own YouTube channel from within the application, instead of being downloaded and re-uploaded by hand.

Why the application requests YouTube access

Moto Edit requests https://www.googleapis.com/auth/youtube.upload for exactly one purpose: to upload a video the user has produced in the application to the user's own YouTube channel, when the user explicitly clicks Publish.

Separately and only if the user chooses it, the application can request https://www.googleapis.com/auth/youtube so that an uploaded video can be added to one of the user's own playlists. This is an opt-in second authorization with its own consent screen; the application never requests it as part of normal sign-in, and every feature works without it.

The user chooses the title, description, tags, and privacy setting in the application, then confirms the upload. Only that video file and those details are sent to YouTube.

The upload scope does not grant, and the application does not request, access to watch history, subscriptions, comments, analytics, or any other Google account data. Nothing is read from the user's account beyond the name of the channel being published to, which is displayed in the application so the user can confirm the correct account is connected.

When the optional playlist authorization is granted, the application additionally reads the titles of the user's own playlists in order to show a chooser, and adds an uploaded video to the playlist the user selects. It is not used for anything else: no playlist is created, renamed, reordered or deleted, and no video other than one the user has just published is ever touched.

The connection is optional — every other feature works without it. It can be revoked at any time from the application's Unlink button, which deletes the stored authorization, or from the Google account permissions page.

Moto Edit's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements. Full details are in the privacy policy.

How data is handled

Moto Edit runs on a single computer owned and operated by an individual in Rochester, New York. Uploaded video never leaves that machine except when the user explicitly publishes it to their own YouTube channel. All video analysis — highlight detection, license-plate and bystander blurring, and matching footage against a written description — runs locally on that machine using models stored on it. No video is sent to any external analysis service, and no uploaded content is used to train any model. There is no advertising, no analytics, and no tracking.

Who can use it

Moto Edit is a private, single-operator application. The application itself is password-protected at edit.caboose-ai.io and there is no public sign-up; this page describes the application publicly for transparency and for API review. It is operated as a non-commercial personal project.
